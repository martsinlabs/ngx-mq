# Security Policy

## Supported versions

Security fixes are provided for the latest release of each active major line:

| Version | Supported |
| ------- | --------- |
| 3.x     | Yes       |
| 2.x     | Yes       |
| 1.x     | Yes       |

## Reporting a vulnerability

Please **do not** report security issues through public GitHub issues, pull requests, or discussions.

Instead, report them privately through GitHub's
[Report a vulnerability](https://github.com/martsinlabs/ngx-mq/security/advisories/new) form. This
opens a private security advisory visible only to the maintainers.

When reporting, include as much of the following as you can:

- A description of the issue and its potential impact.
- Steps to reproduce, ideally with a minimal proof of concept.
- The affected `ngx-mq` and Angular versions.

## What to expect

- We aim to acknowledge new reports within **5 business days**.
- We will keep you informed about the progress toward a fix.
- Once a fix is released, we will credit you in the advisory unless you prefer to remain anonymous.

Thank you for helping keep `ngx-mq` and its users safe.
